# AI Usage Disclosure

## Purpose

AI assistance was used as a development aid while building the Salary
Management System. The application code, configuration, tests,
deployment, and final verification were carried out as part of the
project workflow.

## Areas Where AI Assistance Was Used

AI assistance helped with: - Breaking the assessment requirements into
implementation steps. - Planning the Rails API and React frontend
structure. - Drafting and reviewing code for models, controllers,
routes, and frontend components. - Creating and refining backend
tests. - Troubleshooting deployment configuration, including PostgreSQL
configuration and CORS. - Preparing setup instructions, deployment
steps, and project documentation. - Drafting a short demo script.

## Developer Review and Verification

AI-generated suggestions were not treated as automatically correct.
Changes were applied and checked in the project environment. The backend
test suite was run successfully with **15 tests and 47 assertions**, and
the deployed frontend and backend were manually verified.

## Tools and Technologies

-   ChatGPT: planning, coding assistance, troubleshooting, and
    documentation support.
-   Ruby on Rails, React, Vite, SQLite, PostgreSQL, Git/GitHub, Render,
    and Vercel: project implementation and deployment technologies.

## Responsibility

The project owner is responsible for reviewing the code, understanding
the implementation, protecting credentials, and ensuring that the
application meets the assessment requirements. Secrets such as database
credentials and the Rails master key should remain in environment
configuration and must not be committed to the repository.
